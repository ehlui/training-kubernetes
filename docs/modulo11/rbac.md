El RBAC es una API que dispone kubernetes para gestionar [autorizaciones](https://kubernetes.io/docs/reference/access-authn-authz/authorization/) mediante **roles**. 

- La [autentificación](https://kubernetes.io/docs/reference/access-authn-authz/authentication/) sería el primer paso para detectar quién accede al clúster, y la autorización sería **qué** permisos tiene ese usuario sobre **qué** recursos.
